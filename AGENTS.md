# Repository guidance

Before changing GitHub Actions or distribution code, read:
- [.trellis/spec/distribution/index.md](.trellis/spec/distribution/index.md)
- [.trellis/spec/guides/github-actions.md](.trellis/spec/guides/github-actions.md)

Keep music-player implementation and task records in this repository. Read the
active task's PRD, design and implementation plan before nontrivial changes.
Do not infer production compatibility from a successful compile or from an
unrelated project's documentation. Do not access production through SSH.
